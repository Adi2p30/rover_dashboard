# Fault scenarios

* [normal](normal.md) - baseline operation, no injected fault.
* [joint_overheat](joint-overheat.md) - a joint's cooling term fails and its temperature ramps up.
* [battery_drain](battery-drain.md) - state of charge collapses abnormally fast.
* [sensor_dropout](sensor-dropout.md) - the IMU orientation topic stops publishing.
* [comms_loss](comms-loss.md) - the comms heartbeat topic stops publishing.
* [wheel_slip_stall](wheel-slip-stall.md) - a wheel stalls while commanded speed stays nominal.
